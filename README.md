# Playcus submodule-core
Services and components for general purposes.

## Start new project
* Fork from template project https://gitlab.com/playcus/unity-submodules/project-template

## Connect to exist project
* Connect as Git Submodule in Assets/submodule-core
* Setup project constants [ProjectConstants](https://gitlab.com/playcus/unity-submodules/submodule-core/blob/master/ProjectConstants.cs)

## Script defined symbols
* #SDK_FACEBOOK - in project  installed facebook sdk
* #SDK_FACEBOOK_CANVAS - webgl version of facebook sdk
* #SDK_FIREBASE - in project  installed firebase sdk
* #SDK_APPSFLYER - in project  installed appsflyer sdk
* #SDK_ADJUST - in project  installed appsflyer sdk
* #SDK_GA - in project installed gameanalytics sdk
* #SDK_DELTADNA - DeltaDNA sdk installed in project
* #SDK_APPLOVIN - Applovin sdk installed in project (as mediator)
* #SDK_ADMOB - Admob sdk installed in project (as mediator)
* #SDK_FYBER_OFFER - Fyber offers sdk installed in project
* #SDK_ONESIGNAL - OneSignal sdk installed in project
* #SDK_TOASTS_UWP - Windows toast sdk installed in project
* #TextMeshPro - in project  installed text mesh pro package
* #GDPR - project compilation with gdpr compliance (project files need be prepared) [Instruction](https://www.wrike.com/open.htm?id=539551996)
